# Lidcheck downloads

Desktop builds of Lidcheck, the used-MacBook inspection app.

Download the latest version from the [Releases page](https://github.com/homayacob/lidcheck-releases/releases/latest):

- `Lidcheck-mac-arm64.zip`: Mac with Apple chip (M1 and newer)
- `Lidcheck-mac-x64.zip`: Mac with Intel chip
- `Lidcheck-win32-x64.zip`: Windows 64-bit
